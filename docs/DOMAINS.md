# Domains

Canonical product: **aft.page** (owned, Cloudflare Registrar).

## Suggestion: `vercel.com` vs `*.vercel.app`

| Vercel | Job | aft |
| --- | --- | --- |
| `vercel.com` | company, marketing, dashboard | **`aft.page` apex** (login, drop, docs) |
| `*.vercel.app` | customer apps | **`*.aft.page`** |

Same split, **one registrable name.** Apex = us, stars = them. You already have this.

Do **not** map `tryaft.ai` → `vercel.com` and `aft.page` → `vercel.app`. Vercel kept the **same word** on both TLDs (`vercel` + `.com` / `.app`). `tryaft.*` is a different word. That would make the memorable TLD plumbing and the generic “try” name the company — backwards.

`tryaft.com` is only a spoken alias (301), like a misspelling domain, not the `.com` half of a Vercel pair.

True two-TLD clone would be `aft.com` (taken) + `*.aft.page`, or later `aft.app` + `*.aft.page`. Not worth it until cookies on `.aft.page` collide with tenant apps. Then move dashboard to `app.aft.page` or `tryaft.com`; deploys stay `*.aft.page`.
