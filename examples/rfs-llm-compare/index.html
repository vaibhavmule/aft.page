What this round did

Round 2 still had wiggle room. 1.2 removes it. The remaining fight is one default: is an unclaimed agent deploy a public URL, or a secret preview.

Gemini

Alex at 5–50 is the beachhead. Sarah at 120 dies in infosec. Targeting 50–500 is how you miss the 30-day window.

  • Ten DM scripts, all <4 lines, all 8–50 person titles. Failure mode: hunt 50–500 and get zero second users.
  • Unclaimed: ?key= 32-char bearer. No key → 403 + Claim. Key sets a short-lived cookie. Agents must store the full URL. Failure: user loses the token string and the app is gone until redeploy.
  • Next 60 days: static + client-side fetch only. Do not invite Worker/Next. No Firecracker, no egress proxy, no fork-to-inspect (walked back its own round-2 feature).
  • State: two people cannot return to a forgetful tracker. Smallest primitive: window.AFT.storage on CF KV/DO. Proof app: standup/blocker tracker. Failure: agents use localStorage and state never shared.
  • Charge: 1 creator + 1 invitee free (protects the proof pair). Second invite (3 people) → $15/builder. Failure: creator won’t pay $15 personally and deletes the extra user.

Grok

Keep public-first. MCP still returns a live public URL. Louder claim UI, not a new default.

  • Only voice that refuses the token-gate. Says private-first breaks the agent one-shot. Security = messaging + idle-delete, not visibility.
  • Isolated (when you get there): CF Dynamic Workers/Sandbox, zero egress until owner approves capabilities, secrets as bindings, inviter cannot elevate the code. No Firecracker. Until then: proof may be static-only. Yes.
  • Sep 10 gate: invite accepted and second person used it again the following week. Open-but-not-return fails the week, not the company.
  • Do not charge a 3-person private app during the gate. Pricing starts the day after 2026-09-10.
  • KV is a new product line. Frozen. Static two-person weekly use is valid proof.

Claude

A freeze that bends for “the tracker must remember rows” isn’t a freeze. The deploy is the write.

  • Walked back KV-as-next-build. Same-URL update + edit invite = Doc model: agent regenerates rows, redeploys, bookmark updates. Proof app: Alex’s delivery-exceptions board, baked-in rows, ≥2 redeploys/week, cofounder on view, both back week 2. KV unfreezes only if the gate fails because the invitee wanted to check a box in the browser.
  • $0 now. Hand-onboarded $49 is politeness. Trigger stays second app on the same domain (can be Alex’s second tool). If week 6 nobody crosses it, one manual card ask — if no, workspace SKU is imaginary.
  • Next: off site/docs this week; runtime stays unlabeled. Agents that emit Next: accept + one line “experimental.” If >30% of stranger deploys are Next by October, burying it was optimizing for Guillermo.
  • Visibility keys on auth, not channel. Unauthenticated Drop/CLI/MCP → public but unguessable. Authenticated → private-by-default. Claim of an unguessable site flips private by default, one tap to keep public. “Private with no owner” is incoherent.
  • 15 deployers with no second person: ask if anyone at work saw the tool. Screen-share/Slack = funnel failure (watch five invites live). Nobody saw it = ICP failure (you recruited hobbyists). Stop Oct 15: after 20 screened deployers, <3 accepted invites and zero week-2 returns → freeze becomes permanent. Don’t feature past the silence.

ChatGPT

deploy returns a private action URL. The slug is reserved and unauthorized until claim. Fragment token, not a query string.

  • Agent prints one clickable open_url with token in the hash (not logs/referrers). Slug reserved, 403 without preview. Claim binds history, revokes preview, promotes slug, private by default. Still one command, no login before deploy. Query-param tokens (Gemini) are the weaker design.
  • Cookie split is a real class: Domain=.aft.page sends the session to slug.aft.page. HttpOnly does not stop the browser sending it to user code. One-day audit + smallest fix: __Host-aft_session, no Domain, strip cookies before user runtime. MDN cookies · OWASP cookie attributes
  • 8-line outreach + 5 disqualifies. No second person: “Then it isn’t the test I’m running.”
  • First invoice after proof, when a company rep (not only the creator) must own, revoke, and govern a secret. Deploy/invite/founder-pay are not invoices.
  • Q4 only two: isolated execution and deny-by-default capability broker, together. Accept broken: trust screen, company env, OIDC, audit. Keep ICP technical until the trust screen exists.

  • Sep 10 / week-2 return is the number. Open without return is a miss, not a company funeral (Grok). Claude adds a hard stop Oct 15 if still zero.
