    FAQ

    Do I need an account?

    No. Anonymous deploys work today. Claiming a site comes later.

    Will someone overwrite my page?

    No. If a slug is taken, we add a suffix (e.g. about-me-mist). Existing sites stay put.

    What can I paste?

    A single HTML document, or up to 50 static files (HTML, CSS, JS, images) totaling 5 MB.
