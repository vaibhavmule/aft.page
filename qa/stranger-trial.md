# Stranger unassisted trial (gate before Code)

**Rule:** One person who did **not** build AFT runs either `aft deploy` **or** Run from public docs alone. Capture friction before extending Code.

## Instructions for the stranger

1. Use only https://aft.page (install / Run / docs). No Slack backchannel from the founder during the trial.
2. Pick one:
   - **CLI:** `curl -fsSL https://aft.page/install \| sh` then `aft deploy` in a tiny HTML or Vite folder.
   - **Run:** open https://aft.page/run and paste a public GitHub URL.
3. Stop when you have a live `*.aft.page` URL, or after 20 minutes stuck.
