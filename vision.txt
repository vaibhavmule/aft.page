# aft.page — vision
# Updated: 2026-08-10

Mission: **a cloud for small software.** Purpose-built software for one person
or a small handful should be as easy to deploy and share as a Google Doc.

Belief: coding’s YouTube moment — creation got easy; **publish is the gap.**
We are the host + share half, not the consumer Cursor. [`youtube-moment.txt`](youtube-moment.txt).

The product expands with what AI creates — not with website-builder features.

## Company shape (vision ideas)

- **Solo by design.** Not a gap to fill for fundraising optics.
- **2024–26 Altman:** betting pool on the first **one-person billion-dollar
  company**; future looks like **one person + a ton of compute/agents** — not
  “you need 2–3 founders or funds quietly punish you.”
- aft is on that thesis: agents build the software; aft makes it live + shareable;
  the founder orchestrates agents + infra, not a classic headcount company.
- **Ambition: Telegram founder (Durov) — company *and* life.** Tiny team / hire late *and* the personal standard: sober (don’t drink), strong body, high discipline, freedom to live where the work is (e.g. Dubai). Not “founder cosplay” — operating system for becoming one. Details in `FOUNDER.md` §10.

## Today

Deploy HTML.

Paste, upload, or MCP → live URL.
No account. No website builder. Agent-first.

## Tomorrow

Deploy useful small software an AI creates.

Same job: turn agent output into something durable that you can open again,
update, and share. Grow from static files to state, APIs, secrets, background
work, and full-stack runtimes without exposing cloud complexity.

## Eventually

- HTML
- dashboards
- reports
- mini apps
- personal tools
- team workflows
- full-stack apps

The constant: agent (or human) made it → aft.page makes it live, persistent, and
shareable. The variable is the runtime the app needs.

## Not the vision

Not “build your website.”
Not another Carrd / page builder.
Not ads on user pages.
Not primarily an enterprise governance control plane.
Not a cloud optimized for Big Software scale.

Positioning test: the first five seconds should scream
“AI generated this” — not “build a site.”
