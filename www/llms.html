aft.page

Last updated: 8 August 2026

aft.page is a cloud for small software. It turns software an AI agent builds into a live, shareable HTTPS URL in seconds — no repository, cloud account, or build setup.

aft.page (also referred to as aft or AFT) hosts personal and small-team software created by AI agents. Deploy by Drop, paste, or MCP; then claim, share, and update the same durable *.aft.page URL. The name comes from the aft of a ship (the back of the vessel).

Services

  • Drop deploy — upload a folder or zip and get a live URL instantly, no account required
  • Agent MCP deploy — deploy, aft_deploys, aft_rollback, aft_health at mcp.aft.page/mcp
  • Agent Plugin — npx plugins add vaibhavmule/aft.page for Claude Code, Cursor, Codex, Copilot, VS Code, Grok, and Kimi
  • API deploy — POST /v1/deploy and token-based redeploy
  • Projects — claim on the live slug URL, then share like a Doc
  • Custom domains — after claim, request access, CNAME to cname.aft.page (invite-only during beta)
  • Hosted small software — durable HTTPS URLs for agent-built HTML and small apps

What We Do Not Do

  • Website builder or drag-and-drop page designer
  • Chat product or background coding-agent runner
  • Big Software cloud accounts, repos, or CI setup
  • Guaranteed enterprise SLAs during free beta
  • Ownership of user content on *.aft.page (belongs to the deployer)

MCP tools

Thin deploy adapter only (not a control plane):

  • deploy — html or files → live URL (edit_token → same slug)
  • aft_deploys — list rollback history
  • aft_rollback — restore a prior deployId (same URL)
  • aft_health — ping the API
