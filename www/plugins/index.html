Agent Plugin

Deploy HTML or small static sites to a live URL, no account required for first deploy.

  1. Install the plugin

    Run this in your agent's terminal or environment:

    npx plugins add vaibhavmule/aft.page

    Then restart your agent for the plugin to load.

  2. MCP-only fallback

    If your environment doesn't support plugins, add the remote MCP manually:

    {
  "mcpServers": {
    "aft-page": {
      "url": "https://mcp.aft.page/mcp"
    }
  }
}

  3. Deploy

    Once the plugin is loaded, prompt your agent:

    Deploy this to aft.page

    Your agent will build the project if needed and deploy it to a live URL.

Safety note: First deploy is public immediately. Claim the URL when returned to manage it privately. Unclaimed deploys are deleted after 30 days of inactivity.
