    Why a link beats a file

    1. Opens anywhere Phone, laptop, someone else’s machine — same URL.

    FAQ

    Can I make the link private?

    Yes after you claim. Make it private and invite by email — revoke anytime. Own domain: project Domains tab (request access), CNAME to cname.aft.page.

    Can my agent share the link for me?

    Yes. Wire MCP and ask the agent to deploy — it returns the live URL.

    Agents already build the HTML — aft.page’s home is for that loop. This page is for humans who just need a link right now.
