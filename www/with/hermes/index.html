Deploy from Hermes

Point Hermes at aft.page MCP so CLI and messaging agents can publish a durable URL.

  1. Add aft.page via Hermes MCP CLI

    Preferred:

    hermes mcp add aft-page --url https://mcp.aft.page/mcp

  2. Or edit config

    Add under mcp_servers in ~/.hermes/config.yaml (HTTP/url transport):

    mcp_servers:
  aft-page:
    url: https://mcp.aft.page/mcp

  3. Ask Hermes to deploy

    In Hermes:

    Deploy this HTML to aft.page

Hermes MCP docs apply; aft exposes deploy tools only. /mcp.
